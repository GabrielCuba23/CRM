# CRM

CRM inicial para registrar, buscar y eliminar clientes. Los datos se guardan en el almacenamiento local del navegador.

## Desarrollo

Desde la raíz del repositorio, con Python 3 instalado:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Abre el servidor en tu navegador. No requiere instalar dependencias.

Esta versión es un prototipo local: no incluye autenticación, servidor de datos ni sincronización entre usuarios. No uses información sensible en ella.
