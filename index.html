CONECTA CUANDO LO NECESITES

        
Zapier, Make o n8n

        

          Una herramienta externa puede recoger tareas programadas y devolver su
          resultado. WhatsApp por wa.me abre la conversación con el
          texto preparado; no envía mensajes por sí solo.
        

        

          Integración preparada, sin conectar.
        

        
        
Conexión opcional

        

          Ver guía de conexión y ejemplos para Zapier, Make y n8n
        

        
    
          
  1. 
            Publica la versión privada en Cloudflare y configura un secreto
            INTEGRATION_API_TOKEN de al menos 32 caracteres.
          
    2. 
          
  2. 
            Protege el acceso de la herramienta siguiendo la guía de
            integración. El token va en la herramienta externa, nunca en una
            plantilla.
          
    3. 
          
  3. 
            Programa una llamada POST /api/integration/claim con
            {"limit":10} y la cabecera
            Authorization: Bearer TOKEN.
          
    4. 
          
  4. 
            Cada tarea incluye texto, destinatario, enlace WhatsApp y una clave
            de reserva. Para envío automático conecta un proveedor oficial de
            WhatsApp; para envío manual prepara una notificación con el enlace.
          
    5. 
          
  5. 
            Confirma el resultado con POST /api/integration/ack. No
            marques como enviado un mensaje cuyo único paso fue abrir el enlace.
          
    6. 
        

        

          Zapier, otros servicios y los proveedores de WhatsApp pueden tener
          límites o costes. La conexión permanece desactivada mientras no
          instales el secreto.
        

        
Historial de tareas

        

          Una tarea reservada no se reasigna automáticamente: revisa resultados
          inciertos para evitar duplicados.
